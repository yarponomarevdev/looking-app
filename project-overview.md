## Описание проекта

**Looking** — мобильное приложение для поиска и бронирования стилистов в торговых центрах Москвы.

Клиент может найти стилиста на карте в режиме реального времени, выбрать ТЦ, забронировать встречу и совместно подбирать одежду в магазинах.

Каждый пользователь и стилист имеет личный кабинет с функцией “гардероба” — сохранение артикулов и подобранных луков.

**Миссия:** сделать моду доступной и персонализированной, объединяя покупателей и стилистов на одной платформе.

## Цель и MVP-версия

Задача MVP — протестировать пользовательскую ценность (поиск стилиста и бронирование) и подтвердить интерес аудитории перед масштабированием и интеграцией с ТЦ/магазинами.

MVP должно быть опубликовано в **Google Play** и **App Store** в виде PWA или WebView-приложения с минимальным дизайном и интерфейсом на **русском языке**.

---

## Основные (core) функции MVP

1. **Карта со стилистами в реальном времени**
    - Отображение активных стилистов “в работе сейчас”.
    - Локация по ближайшему ТЦ или метро.
    - Возможность перейти в профиль стилиста.
2. **Профиль стилиста**
    - Фото, краткое описание, портфолио.
    - Статус (“Свободен сейчас” / “Занят”).
    - Кнопка “Забронировать встречу”.
3. **Бронирование**
    - Выбор даты, времени и места (ТЦ).
    - Подтверждение по email (через **Resend API**).
    - Подтверждение отображается в профиле.
4. **Гардероб**
    - Возможность сохранить выбранные вещи (артикулы, фото).
    - Сортировка по магазинам и образам.
5. **Личный кабинет**
    - Для клиента: история встреч, избранные стилисты, гардероб.
    - Для стилиста: активные заказы, статус, редактирование профиля.

## Стек технологий

- **Frontend:** Next.js (v0.dev) / React
- **Backend:** Supabase (аутентификация, база данных, API)
- **Email-сервис:** Resend (подтверждение бронирования)
- **Картографический сервис:** *Яндекс.Карты API* (оптимально для рынка РФ: устойчивость, русская локализация, поддержка маршрутов внутри ТЦ). Альтернатива — 2GIS API или Mapbox (при необходимости офлайн-режима).
- **Хостинг и CI/CD:** Vercel
- **Мобильная упаковка:** Capacitor / Expo WebView (для публикации в сторах)
- **Дизайн:** минимальный, адаптированный под мобильные устройства.

## Пользовательский поток (User Flow)

**Пользователь:**

1. Открывает приложение → видит карту с активными стилистами.
2. Кликает по стилисту → видит профиль.
3. Нажимает “Забронировать” → выбирает дату, время, ТЦ.
4. Получает email-подтверждение → встречается в офлайн-формате.
5. После встречи сохраняет луки в гардероб.

**Стилист:**

1. Заходит в личный кабинет.
2. Активирует статус “Работаю сейчас”.
3. Принимает бронирования → подтверждает участие.
4. Добавляет образы в гардероб клиента.

## Case Study / MVP Value

- **Гипотеза:** пользователи хотят бесплатное сопровождение при покупках, а стилисты — постоянный поток клиентов.
- **Метрика успеха:**
    - 100–200 пользователей в Москве за 2 месяца;
    - положительный retention (повторные заказы без рекламы);
    - 3–5 стилистов-партнёров, активных ежедневно.
- **Монетизация:** комиссия 10% с продаж магазинов.
