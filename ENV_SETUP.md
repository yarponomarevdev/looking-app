# Настройка переменных окружения

## Быстрая настройка

1. Создайте файл `.env` в корневой директории проекта `looking-app/`:

```bash
# Для Windows (PowerShell)
New-Item -Path .env -ItemType File

# Для macOS/Linux
touch .env
```

2. Откройте файл `.env` и добавьте следующее содержимое:

```env
# Яндекс.Карты API ключ
# Получите ключ на https://developer.tech.yandex.ru/
YANDEX_MAPS_API_KEY=ваш_реальный_api_ключ_яндекс_карт
```

3. Замените `ваш_реальный_api_ключ_яндекс_карт` на ваш реальный API ключ Яндекс.Карт

## Как получить API ключ Яндекс.Карт

1. Перейдите на сайт [Яндекс.Карты для разработчиков](https://developer.tech.yandex.ru/)
2. Войдите в свой аккаунт Яндекс или создайте новый
3. Перейдите в раздел "Мои ключи" или "API ключи"
4. Создайте новый ключ для MapKit
5. Скопируйте полученный ключ и вставьте в файл `.env`

## Важные замечания

- ❗ Файл `.env` уже добавлен в `.gitignore` и **НЕ будет** загружен в Git
- ✅ Это безопасный способ хранения секретных ключей
- 📝 При развертывании на сервере создайте файл `.env` там же
- 🔄 После изменения `.env` необходимо перезапустить Metro bundler (`npm start`)

## Проверка настройки

После создания файла `.env` запустите приложение:

```bash
npm start
```

Если все настроено правильно, Яндекс.Карты загрузятся без ошибок.

## Решение проблем

### Ошибка "Cannot find module '@env'"

Решение:
1. Убедитесь, что установлены все зависимости: `npm install`
2. Очистите кеш Metro: `npx expo start -c`
3. Перезапустите приложение

### Карта не загружается

Проверьте:
1. API ключ правильно указан в `.env`
2. API ключ активирован в консоли Яндекс.Карт
3. У ключа есть права на использование MapKit
