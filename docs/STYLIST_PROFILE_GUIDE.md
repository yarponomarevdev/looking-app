## Обзор профиля стилиста

Профиль стилиста в Looking содержит всю необходимую информацию для клиентов:

- ✅ **Основная информация**: ФИО, фото, статус
- 📍 **География**: торговые центры, где работает стилист
- 👔 **Специализация**: бренды одежды, с которыми работает
- 📱 **Контакты**: социальные сети для связи
- 📅 **Доступность**: график работы по дням недели
- 📷 **Портфолио**: фотографии работ

---

## Поля профиля

### 1. Фамилия Имя Отчество

**Поле:** `full_name` (из таблицы `profiles`)

**Описание:** Полное имя стилиста  
**Формат:** Текст  
**Обязательно:** Да  
**Редактирование:** Указывается при регистрации (пока не редактируется в приложении)

**Пример:**
```
Иванова Анна Сергеевна
```

---

### 2. Фото профиля

**Поле:** `avatar_url` (из таблицы `profiles`)

**Описание:** URL фотографии стилиста  
**Формат:** TEXT (ссылка)  
**Обязательно:** Нет  
**Редактирование:** Пока не реализовано в приложении (запланировано)

**Рекомендации:**
- Фото лица крупным планом
- Профессиональная фотография
- Хорошее освещение

---

### 3. Статус

**Поле:** `status`

**Описание:** Текущая доступность стилиста  
**Формат:** ENUM (`'available'`, `'busy'`, `'offline'`)  
**Обязательно:** Да (по умолчанию: `'available'`)

**Значения:**
- **`available`** (Свободен) - стилист доступен для записи ✅
- **`busy`** (Занят) - временно занят, но онлайн ⏳
- **`offline`** (Офлайн) - не работает, скрыт из списка ⛔

**Редактирование:**
- В профиле есть кнопки для быстрого переключения статуса
- Изменения сохраняются мгновенно
- При статусе `'offline'` стилист не отображается на карте

---

### 4. Социальные сети

**Поле:** `social_links` (JSONB)

**Описание:** Контакты для связи  
**Формат:** JSON объект  
**Обязательно:** Нет

**Структура:**
```json
{
  "instagram": "username",
  "vk": "https://vk.com/username",
  "telegram": "@username",
  "whatsapp": "+79991234567"
}
```

**Поддерживаемые платформы:**
- 📷 Instagram
- 🔵 VK (ВКонтакте)
- ✈️ Telegram
- 💬 WhatsApp

**Рекомендации:**
- Instagram: только username без @
- Telegram: с символом @
- WhatsApp: номер в международном формате
- VK: можно ссылку или username

---

### 5. Информация о себе

**Поле:** `bio`

**Описание:** Текст о себе, опыте, специализации  
**Формат:** TEXT  
**Обязательно:** Да  
**По умолчанию:** "Расскажите о себе и своем опыте работы стилистом"

**Рекомендации:**
- Опыт работы стилистом
- Специализации (casual, business, evening и т.д.)
- Образование и сертификаты
- Личный подход к клиентам
- Достижения

**Пример:**
```
Профессиональный стилист с опытом работы 5+ лет. 
Специализируюсь на создании индивидуального стиля для 
деловых людей. Окончила школу стилистов при МГУДТ. 
Помогу подобрать гардероб, соответствующий вашему образу 
жизни и бюджету.
```

---

### 6. График работы

**Поле:** `work_schedule` (JSONB)

**Описание:** Расписание по дням недели  
**Формат:** JSON объект  
**Обязательно:** Да (создается автоматически)

**Структура:**
```json
{
  "monday": {
    "enabled": true,
    "start": "10:00",
    "end": "20:00"
  },
  "tuesday": { ... },
  // ... остальные дни
}
```

**Параметры дня:**
- `enabled` (boolean) - работает ли стилист в этот день
- `start` (string) - время начала работы (формат "HH:MM")
- `end` (string) - время окончания работы (формат "HH:MM")

**По умолчанию:**
- Пн-Пт: 10:00 - 20:00 (включено)
- Суббота: 11:00 - 19:00 (включено)
- Воскресенье: выходной (выключено)

**Редактирование:**
- Включение/выключение дней через переключатель
- Указание времени начала и окончания
- Поля времени отображаются только для включенных дней

## Редактирование профиля

### Доступ к редактированию

1. Войдите в приложение как стилист
2. Перейдите во вкладку **"Профиль"**
3. Нажмите **"✏️ Редактировать профиль"**

### Интерфейс редактирования

Экран разделен на секции:

#### 1. Текущий статус
- 3 кнопки для быстрого переключения
- Изменения применяются мгновенно
- Отдельный вызов API для статуса

#### 2. О себе
- Многострочное текстовое поле
- Минимум 20 символов (рекомендуется)

#### 3. Социальные сети
- 4 поля для разных платформ
- Опциональное заполнение
- Подсказки по формату

#### 4. Торговые центры
- Список тэгов с выбором
- Обязательно выбрать минимум 1 ТЦ
- Валидация при сохранении

#### 5. Бренды одежды
- Выбранные бренды отображаются сверху
- Можно удалять одним тапом (✕)
- Добавление своего бренда через поле ввода

#### 6. График работы
- 7 дней недели
- Переключатель вкл/выкл для каждого дня
- Поля времени (начало и конец)
- Формат: HH:MM (например, 10:00)

### Сохранение

- Кнопка **"Сохранить изменения"** внизу экрана
- Валидация: минимум 1 ТЦ
- При успехе: уведомление + возврат в профиль
- При ошибке: сообщение об ошибке

## Структура базы данных

### Таблица `stylists`

```sql
CREATE TABLE stylists (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES profiles(id) UNIQUE,
  bio TEXT,
  status TEXT CHECK (status IN ('available', 'busy', 'offline')) DEFAULT 'available',
  latitude DOUBLE PRECISION,
  longitude DOUBLE PRECISION,
  malls TEXT[],                  -- Массив ТЦ
  brands TEXT[],                 -- Массив брендов
  social_links JSONB,            -- Социальные сети
  work_schedule JSONB,           -- График работы
  portfolio_images TEXT[],
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);
```

### Связь с `profiles`

```sql
-- full_name и avatar_url хранятся в profiles
SELECT 
  s.*,
  p.full_name,
  p.avatar_url
FROM stylists s
JOIN profiles p ON s.user_id = p.id;
```

## FAQ

### Можно ли работать в нескольких ТЦ?

Да! Выберите все ТЦ, в которых вы работаете. Клиенты увидят полный список в вашем профиле.

### Как изменить статус на "Занят"?

В профиле нажмите кнопку **"⏳ Занят"** в секции "Текущий статус". Изменение произойдет моментально.

### Что делать, если нужного бренда нет в списке?

Внизу секции "Бренды" есть поле "Добавить свой бренд". Введите название и нажмите "Добавить".

### Обязательно ли заполнять социальные сети?

Нет, это опционально. Но рекомендуется указать хотя бы один способ связи для быстрой коммуникации с клиентами.

### Можно ли работать только по выходным?

Да! В графике работы отключите будние дни и включите только субботу и воскресенье.

### Что означает статус "Офлайн"?

При статусе "Офлайн" ваш профиль скрыт из списка и с карты. Используйте его, когда временно не принимаете клиентов.

### Как часто обновлять профиль?

Рекомендуется обновлять:
- **Статус**: ежедневно или по мере необходимости
- **График работы**: при изменении расписания
- **ТЦ и бренды**: раз в месяц или при изменении специализации
- **Био**: раз в квартал для актуальности
