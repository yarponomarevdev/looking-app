# Функционал "Избранное" для клиентов

## Обзор

Клиенты могут добавлять понравившиеся образы в избранное и просматривать их в удобной галерее прямо в своем профиле.

## Где находится

**Для клиентов:**
```
Профиль → Секция "Избранное" (горизонтальная галерея)
```

**Для стилистов:**
Секция "Избранное" не отображается (у них есть "Мои образы")

## Функциональность

### Добавление в избранное

**Из ленты:**
1. Откройте вкладку **"Лента"**
2. Найдите понравившийся образ
3. Нажмите на **сердечко ❤️** на карточке
4. Сердечко станет красным - образ добавлен

### Просмотр избранного

**В профиле:**
1. Откройте вкладку **"Профиль"**
2. Секция **"Избранное"** покажет все избранные образы
3. Прокрутите галерею горизонтально

**Информация в галерее:**
- Фото образа
- Название образа
- Имя стилиста (под названием)
- Счетчик: "3 образа" / "5 образов"

### Быстрый заказ образа

**Из избранного:**
1. Откройте **"Профиль"** → **"Избранное"**
2. **Нажмите на фото** образа
3. Автоматически откроется профиль стилиста
4. Модальное окно бронирования откроется сразу
5. Заполните дату, время, комментарий
6. Нажмите **"Забронировать"**

### Удаление из избранного

**Способ 1: Из профиля**
1. Откройте **"Профиль"** → **"Избранное"**
2. Найдите образ в галерее
3. Нажмите **✕** на карточке
4. Подтвердите удаление

**Способ 2: Из ленты**
1. Откройте **"Лента"**
2. Найдите образ (красное сердечко)
3. Нажмите на **сердечко**
4. Оно станет серым - образ удален

## Технические детали

### База данных

**Таблица `favorite_looks`:**
```sql
- id (UUID)
- user_id (UUID) → profiles.id
- look_id (UUID) → stylist_looks.id
- created_at (timestamp)
- UNIQUE(user_id, look_id) -- один образ один раз
```

### API методы

**В lookStore:**
```typescript
fetchFavorites(userId)             // Загрузка избранного
addToFavorites(userId, lookId)     // Добавить
removeFromFavorites(userId, lookId) // Удалить
isFavorited(lookId)                // Проверка статуса
```

**В ProfileScreen:**
```typescript
loadFavoriteLooks()                    // Полная загрузка
handleRemoveFromFavorites(lookId)      // Удаление с подтверждением
handleBookFavoriteLook(stylistId, lookId) // Переход к заказу
```

### Запрос к БД

```typescript
// Получаем ID избранных
const favorites = await supabase
  .from('favorite_looks')
  .select('look_id')
  .eq('user_id', userId);

// Загружаем полную информацию
const looks = await supabase
  .from('stylist_looks')
  .select(`
    *, 
    stylists:stylist_id (
      *, 
      profiles:user_id (*)
    )
  `)
  .in('id', lookIds);
```

## Сценарии использования

### Сценарий 1: Сбор образов для вдохновения
1. Клиент просматривает ленту
2. Добавляет 10 понравившихся образов
3. Открывает профиль - видит все образы
4. Выбирает лучший для заказа

### Сценарий 2: Отложенное бронирование
1. Клиент нашел образ, но сейчас не готов бронировать
2. Добавляет в избранное
3. Позже возвращается в профиль
4. Нажимает на образ → заказывает

### Сценарий 3: Сравнение стилистов
1. Клиент добавляет образы от разных стилистов
2. В профиле сравнивает их
3. Выбирает лучшего
4. Заказывает консультацию

## Ограничения

✅ **Работает:**
- Неограниченное количество избранных
- Образы от любых стилистов
- Образы сохраняются между сессиями
- Работает даже если стилист неактивен

❌ **Не работает:**
- Нельзя группировать избранное по стилистам
- Нельзя добавлять заметки к образам
- Нет сортировки (только по дате добавления)
- Нет поиска по избранному

## Решение проблем

### Избранное не отображается
1. Проверьте роль: должен быть **клиент**, не стилист
2. Перезапустите приложение
3. Проверьте подключение к интернету

### Образ не удаляется
1. Проверьте подключение к интернету
2. Попробуйте удалить через ленту (нажать на сердечко)
3. Перезапустите приложение

### Клик на образ не открывает стилиста
1. Убедитесь, что у образа есть информация о стилисте
2. Проверьте, что стилист не удалил свой профиль
3. Попробуйте найти образ в ленте и перейти оттуда
