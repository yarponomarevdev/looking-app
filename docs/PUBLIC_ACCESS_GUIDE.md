# Руководство по публичному доступу к приложению

## Описание

Приложение Looking теперь имеет публичный доступ к основным функциям просмотра без необходимости авторизации. Однако функции записи, редактирования и взаимодействия требуют авторизации.

## Структура доступа

### 🌍 Публичные функции (доступны без авторизации)

1. **Лента образов (Feed)**
   - Просмотр всех образов стилистов
   - Просмотр информации о брендах и ценах
   - ❌ Добавление в избранное требует авторизации

2. **Карта стилистов (Map)**
   - Просмотр расположения стилистов на карте
   - Просмотр информации о торговых центрах

3. **Список стилистов (List)**
   - Просмотр списка всех стилистов
   - Фильтрация по торговым центрам

4. **Профиль стилиста (StylistDetail)**
   - Просмотр полной информации о стилисте
   - Просмотр образов, портфолио, графика работы
   - Просмотр социальных сетей
   - ❌ Запись к стилисту требует авторизации

### 🔒 Приватные функции (требуют авторизации)

1. **Избранное**
   - Добавление/удаление образов в избранное
   - Просмотр избранных образов в профиле

2. **Бронирование**
   - Запись к стилисту
   - Просмотр своих записей
   - Управление записями

3. **Уведомления**
   - Просмотр уведомлений о записях
   - Push-уведомления

4. **Для стилистов**
   - Редактирование профиля
   - Создание и управление образами
   - Управление запросами на встречи

## Поведение при попытке доступа к приватным функциям

### Неавторизованный пользователь

Когда неавторизованный пользователь пытается:
- Добавить образ в избранное
- Записаться к стилисту
- Нажать на образ для записи

**Результат:**
1. Появляется toast-уведомление с информацией о необходимости авторизации
2. Автоматический переход на экран авторизации
3. После входа пользователь может вернуться и завершить действие

### Экран профиля для неавторизованных

Вкладка "Профиль" для неавторизованных пользователей показывает:
- Приветственное сообщение
- Список преимуществ авторизации:
  - ❤️ Сохранение избранных образов
  - 📅 Запись к стилистам
  - 🔔 Получение уведомлений
- Кнопку "Войти или Зарегистрироваться"

## Технические детали

### Измененные файлы

1. **`src/navigation/AppNavigator.tsx`**
   - Публичные экраны всегда доступны (Main, StylistDetail)
   - Экран Auth открывается как модальное окно
   - Приватные экраны доступны только после авторизации

2. **`src/screens/ProfileScreen.tsx`**
   - Добавлен гостевой экран для неавторизованных
   - Показывает преимущества регистрации
   - Кнопка перехода к авторизации

3. **`src/screens/FeedScreen.tsx`**
   - Проверка авторизации при добавлении в избранное
   - Toast-уведомление и переход к авторизации

4. **`src/screens/StylistDetailScreen.tsx`**
   - Проверка авторизации перед открытием модального окна бронирования
   - Проверка при клике на образ
   - Проверка при автоматическом открытии по deep link

### Deep Links

Ссылки на образы работают для всех пользователей:
- `https://looking-app.vercel.app?stylist={id}&look={id}`
- Неавторизованные пользователи видят профиль стилиста
- При попытке записаться - переход к авторизации

## UX/UI улучшения

### Toast-уведомления

Используются кросс-платформенные toast-уведомления вместо Alert:
- ✅ Успешные действия - зеленый цвет
- ℹ️ Информация - синий цвет
- ❌ Ошибки - красный цвет

### Модальное окно авторизации

Экран авторизации открывается как модальное окно (`presentation: 'modal'`):
- Плавный переход
- Возможность вернуться назад
- Сохранение контекста предыдущего экрана

## Проверка работы

### Тестовые сценарии

1. **Публичный доступ**
   - Откройте приложение без авторизации
   - Проверьте доступ к ленте, карте, списку стилистов
   - Нажмите на профиль стилиста - должен открыться

2. **Попытка записи без авторизации**
   - Откройте профиль стилиста
   - Нажмите "Записаться"
   - Должно появиться уведомление и переход к авторизации

3. **Избранное без авторизации**
   - В ленте нажмите на сердечко
   - Должно появиться уведомление и переход к авторизации

4. **Deep link без авторизации**
   - Откройте ссылку на образ
   - Должен открыться профиль стилиста
   - При попытке записаться - переход к авторизации

5. **После авторизации**
   - Войдите в систему
   - Все функции должны работать
   - Избранное сохраняется
   - Запись работает
