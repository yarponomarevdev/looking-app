## 🛠 Технологический стек (РЕАЛИЗОВАНО)

- ✅ **Frontend**: React Native + Expo
- ✅ **Backend**: Supabase (Auth, PostgreSQL, Real-time)
- ✅ **Карты**: Яндекс.Карты через WebView (JavaScript API)
- ✅ **State**: Zustand
- ✅ **Навигация**: React Navigation v6
- ✅ **Язык**: TypeScript
- ✅ **Package**: com.looking.app

### Почему Яндекс.Карты через WebView?
- Работает в Expo Go без native модулей
- Полная функциональность JavaScript API
- Не требует сборки для разработки
- Отличная производительность

## 📦 Сборка APK

Приложение **готово к сборке APK** через:

1. **EAS Build** (облачная сборка):
```bash
cd looking-app
eas build --platform android
```

2. **Локальная сборка**:
```bash
cd looking-app
npx expo prebuild
cd android && ./gradlew assembleRelease
```

## 🚀 Как запустить (БЫСТРЫЙ СТАРТ)

### Шаг 1: Перейти в проект
```bash
cd looking-app
```

### Шаг 2: Настроить Supabase (5 мин)
1. Создать проект на supabase.com
2. Выполнить SQL из `supabase-migration.sql`
3. Создать файл `.env`:
```env
EXPO_PUBLIC_SUPABASE_URL=https://ваш-проект.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=ваш-ключ
```

### Шаг 3: Запустить
```bash
npx expo start
```

Сканировать QR код в Expo Go!
