# Обновление: Управление образами из профиля

## Что изменилось

Управление образами стилистов **перенесено** из экрана "Редактировать профиль" прямо на главный экран профиля.

### Было (v1.0.0)
```
Профиль → Редактировать профиль → Секция "Мои образы" (сетка)
```

### Стало (v1.1.0)
```
Профиль → Секция "Мои образы" (горизонтальная галерея)
```

## Преимущества

✅ **Быстрый доступ** - образы на главном экране профиля
✅ **Горизонтальная прокрутка** - удобнее для галереи изображений
✅ **Меньше кликов** - не нужно заходить в редактирование
✅ **Пустое состояние** - понятная кнопка "Добавить первый образ"
✅ **Автозагрузка** - образы загружаются сразу при открытии профиля

## Для пользователей

### Как добавить образ (стилист)

1. Откройте вкладку **"Профиль"**
2. Найдите секцию **"Мои образы"**
3. Нажмите **"+ Добавить"** (или **"Добавить первый образ"**)
4. Выберите фото, заполните название и описание
5. Нажмите **"Добавить"**

### Как удалить образ

1. Откройте вкладку **"Профиль"**
2. Найдите образ в горизонтальной галерее
3. Нажмите крестик **✕** на карточке
4. Подтвердите удаление
