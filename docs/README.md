## Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск разработки

```bash
# Веб-версия
npm run web

# iOS
npm run ios

# Android
npm run android
```

### Сборка для production

```bash
npm run build
```

## Технологии

- **React Native** + **Expo** - кроссплатформенная разработка
- **TypeScript** - типизация
- **Zustand** - управление состоянием
- **React Navigation** - навигация
- **Supabase** - backend и аутентификация
- **React Native Paper** - UI компоненты

## Архитектура

### Frontend

- **Компоненты** - переиспользуемые UI компоненты
- **Экраны** - страницы приложения
- **Stores** - глобальное состояние (Zustand)
- **Hooks** - переиспользуемая логика
- **Navigation** - маршрутизация

### Backend

- **Supabase** - база данных, аутентификация, storage
- **Edge Functions** - serverless функции
- **RLS** - Row Level Security для защиты данных
