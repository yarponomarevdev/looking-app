## ⏳ Требует действий пользователя

### Обязательные шаги перед запуском:

1. **Настроить Supabase** (5 минут)
   - Создать проект на supabase.com
   - Выполнить миграцию из `supabase-migration.sql`
   - Получить URL и anon key
   - Создать файл `.env` с ключами

2. **Получить Google Maps API ключ** (3 минуты)
   - Google Cloud Console
   - Включить Maps SDK for Android
   - Добавить ключ в `app.json`

3. **Первый запуск**
   ```bash
   cd looking-app
   npx expo start
   ```

### Опциональные шаги:

4. **Добавить тестовых стилистов**
   - Через Supabase Table Editor

5. **Собрать APK**
   - EAS Build: `eas build --platform android`
   - Или локально через Gradle
