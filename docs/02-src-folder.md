# Папка src/ - Исходный код приложения

Основная папка с исходным кодом приложения. Содержит все компоненты, экраны, логику и типы.

## Структура

```
src/
├── components/     # Переиспользуемые UI компоненты
├── screens/        # Экраны приложения (страницы)
├── navigation/     # Конфигурация навигации
├── store/          # Управление состоянием (Zustand stores)
├── hooks/          # Кастомные React хуки
├── lib/            # Библиотеки и утилиты
├── types/          # TypeScript типы и интерфейсы
└── constants/      # Константы приложения
```

## components/ - UI компоненты

Переиспользуемые компоненты, сгруппированные по функциональности.

### Структура компонентов

- **alert/** - Компоненты для отображения уведомлений
  - `AlertProvider.tsx` - провайдер для глобальных алертов

- **booking/** - Компоненты для бронирований
  - `BookingCard.tsx` - карточка бронирования
  - `BookingModal.tsx` - модальное окно создания/редактирования бронирования
  - `CustomCalendar.tsx` - кастомный календарь для выбора даты

- **feed/** - Компоненты ленты образов
  - `LookCard.tsx` - карточка образа в ленте
  - `LookDetailModal.tsx` - модальное окно с деталями образа

- **map/** - Компоненты карты
  - `MallStylistsBottomSheet.tsx` - нижняя панель со стилистами торгового центра
  - `StylistBottomSheet.tsx` - нижняя панель с информацией о стилисте

- **notifications/** - Компоненты уведомлений
  - `NotificationBadge.tsx` - бейдж с количеством непрочитанных уведомлений
  - `NotificationSettings.tsx` - настройки уведомлений
  - `PushNotificationPrompt.tsx` - промпт для запроса разрешения на push-уведомления

- **pwa/** - Компоненты для PWA функциональности
  - `UniversalInstallButton.tsx` - кнопка установки приложения
  - `DESIGN_GUIDE.md`, `README.md` - документация по PWA

### Принципы организации

- Каждый компонент находится в своей папке
- Компоненты сгруппированы по функциональности
- Используются named exports
- Компоненты написаны на TypeScript с интерфейсами

## screens/ - Экраны приложения

Экраны (страницы) приложения, которые используются в навигации.

### Список экранов

- `AuthScreen.tsx` - экран авторизации и регистрации
- `FeedScreen.tsx` - лента образов стилистов
- `MapScreen.tsx` - карта со стилистами
- `StylistListScreen.tsx` - список стилистов
- `StylistDetailScreen.tsx` - детальная страница стилиста
- `ProfileScreen.tsx` - профиль пользователя
- `BookingsScreen.tsx` - список бронирований клиента
- `StylistBookingsScreen.tsx` - список запросов на встречи для стилиста
- `NotificationsScreen.tsx` - экран уведомлений
- `EditStylistProfileScreen.tsx` - редактирование профиля стилиста
- `CreateLookScreen.tsx` - создание нового образа

### Особенности

- Каждый экран - отдельный файл
- Экраны используют компоненты из `components/`
- Экраны взаимодействуют со stores из `store/`
- Навигация настроена в `navigation/AppNavigator.tsx`

## navigation/ - Навигация

Конфигурация навигации приложения.

### Файлы

- `AppNavigator.tsx` - главный навигатор приложения

### Структура навигации

1. **Stack Navigator** (верхний уровень)
   - `Main` - табы (Feed, Map, List, Profile)
   - `StylistDetail` - детальная страница стилиста
   - `Auth` - авторизация (модальное окно)
   - Приватные экраны (только для авторизованных):
     - `Bookings` - бронирования клиента
     - `StylistBookings` - запросы стилиста
     - `Notifications` - уведомления
     - `EditStylistProfile` - редактирование профиля
     - `CreateLook` - создание образа

2. **Tab Navigator** (внутри Main)
   - `Feed` - лента образов
   - `Map` - карта
   - `List` - список стилистов
   - `Profile` - профиль

### Deep Linking

Настроена поддержка deep links для:
- Email confirmation (`access_token`, `refresh_token`)
- Шеринг образов (`?stylist=ID&look=ID`)

## store/ - Управление состоянием

Stores на Zustand для глобального состояния приложения.

### Stores

- `authStore.ts` - аутентификация пользователя
  - `session`, `user` - текущая сессия и пользователь
  - `signIn()`, `signUp()`, `signOut()` - методы авторизации
  - `initialize()` - инициализация при старте

- `stylistStore.ts` - данные стилистов
  - Кэширование списка стилистов
  - Методы загрузки и фильтрации

- `bookingStore.ts` - бронирования
  - Управление бронированиями клиента и стилиста
  - Создание, подтверждение, отмена бронирований

- `lookStore.ts` - образы стилистов
  - Лента образов
  - Избранное
  - Создание и редактирование образов

- `notificationStore.ts` - уведомления
  - Список уведомлений
  - Отметка как прочитанных
  - Счетчик непрочитанных

- `pushSubscriptionStore.ts` - push-подписки
  - Управление подписками на push-уведомления
  - Регистрация и удаление подписок

### Принципы

- Каждый store отвечает за свою доменную область
- Stores используют Supabase для работы с данными
- Состояние синхронизируется с backend

## hooks/ - Кастомные хуки

Переиспользуемая логика в виде React хуков.

### Хуки

- `usePushNotifications.ts` - работа с push-уведомлениями
  - Регистрация подписок
  - Обработка входящих уведомлений
  - Инициализация при старте приложения

### Использование

Хуки используются в компонентах и экранах для извлечения логики и переиспользования.

## lib/ - Библиотеки и утилиты

Настройка внешних библиотек и утилиты.

### Файлы

- `supabase.ts` - клиент Supabase
  - Настройка подключения к Supabase
  - Конфигурация аутентификации с AsyncStorage
  - Экспорт готового клиента для использования в приложении

### Особенности

- Используется `react-native-url-polyfill` для совместимости
- AsyncStorage для хранения сессии
- Автоматическое обновление токенов

## types/ - TypeScript типы

Типы и интерфейсы для всего приложения.

### Файлы

- `index.ts` - основные типы приложения
  - `Stylist` - интерфейс стилиста
  - `Profile` - интерфейс профиля пользователя
  - `Booking` - интерфейс бронирования
  - `Notification` - интерфейс уведомления
  - `StylistLook` - интерфейс образа
  - `WorkSchedule` - график работы
  - `SocialLinks` - социальные сети
  - Типы навигации (`RootStackParamList`, `MainTabParamList`)

- `push-subscription.ts` - типы для push-подписок

### Принципы

- Все типы экспортируются из `index.ts`
- Интерфейсы используются вместо type aliases
- Типы синхронизированы со схемой базы данных Supabase

## constants/ - Константы

Статические данные приложения.

### Файлы

- `malls.ts` - список торговых центров
  - Используется для фильтрации стилистов
  - Используется при создании бронирований

### Использование

Константы импортируются в компонентах и экранах для отображения опций и фильтров.
