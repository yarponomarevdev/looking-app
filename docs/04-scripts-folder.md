# Папка scripts/ - Вспомогательные скрипты

Скрипты для автоматизации задач сборки и разработки.

## Структура

```
scripts/
├── generate-icons.js      # Генерация иконок приложения
├── postbuild-web.js       # Постобработка после сборки веб-версии
└── README.md              # Документация скриптов
```

## generate-icons.js

Скрипт для генерации иконок приложения из исходных изображений.

### Назначение

Создает иконки разных размеров для:
- iOS (App Icon)
- Android (adaptive icon, launcher icons)
- Web (favicon, PWA icons)

### Использование

```bash
npm run generate-icons
```

### Зависимости

- `sharp` - для обработки изображений
- Исходные изображения в `assets/`

### Результат

Генерированные иконки сохраняются в:
- `assets/` - для мобильных платформ
- `public/` - для веб-версии

## postbuild-web.js

Скрипт постобработки после сборки веб-версии приложения.

### Назначение

Выполняется автоматически после `expo export --platform web`:
- Копирует файлы из `public/` в `dist/`
- Обновляет пути к ресурсам
- Настраивает PWA манифест
- Оптимизирует файлы для production

### Использование

Вызывается автоматически через npm script:

```bash
npm run build  # Выполняет expo export и postbuild-web.js
```

### Что делает

1. Копирует статические файлы (favicon, manifest.json)
2. Обновляет пути в HTML
3. Настраивает service worker для PWA
4. Оптимизирует размеры файлов

## Интеграция с npm scripts

Скрипты интегрированы в `package.json`:

```json
{
  "scripts": {
    "build": "npx expo export --platform web && npm run postbuild",
    "postbuild": "node scripts/postbuild-web.js",
    "generate-icons": "node scripts/generate-icons.js"
  }
}
```

## Принципы

- Скрипты написаны на Node.js
- Используют стандартные модули или минимальные зависимости
- Логируют процесс выполнения
- Обрабатывают ошибки
