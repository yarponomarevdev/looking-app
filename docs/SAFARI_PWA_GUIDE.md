# Поддержка Safari и iOS

## Поддержка Push-уведомлений в Safari

### История

**До iOS 16.4 (март 2023):**
- ❌ Safari не поддерживал Web Push API
- ❌ PWA не могли отправлять уведомления

**С iOS 16.4+ и macOS Ventura+:**
- ✅ **Полная поддержка** Web Push API
- ✅ Работает на iPhone, iPad, Mac
- ✅ Совместимость со стандартами (VAPID, Service Workers)

### Текущий статус (2024)

Safari **ПОЛНОСТЬЮ ПОДДЕРЖИВАЕТ** push-уведомления, но с некоторыми условиями:

## Требования для Safari

### 1. Минимальные версии

- **iOS**: 16.4 или новее
- **macOS**: Ventura (13.0) или новее
- **Safari**: 16.4+

### 2. PWA должно быть установлено

**Критически важно:** Push-уведомления в Safari работают **ТОЛЬКО** если PWA установлено на устройство.

#### Как установить PWA на iOS:

1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Прокрутите и выберите "На экран «Домой»"
4. Нажмите "Добавить"
5. Откройте приложение с домашнего экрана

#### Как установить PWA на macOS:

1. Откройте сайт в Safari
2. Файл → Добавить на Dock
3. ИЛИ нажмите иконку в адресной строке

### 3. HTTPS обязателен

- Safari требует валидный SSL сертификат
- localhost не работает (в отличие от Chrome)
- Самоподписанные сертификаты не принимаются

## Ограничения Safari

### 1. Запрос разрешений

**Нельзя:**
- Запрашивать разрешение сразу при загрузке
- Показывать промпт без взаимодействия пользователя

**Нужно:**
- Запрашивать только после действия пользователя (клик на кнопку)
- Объяснить, зачем нужны уведомления

### 2. Частота уведомлений

Safari может ограничивать:
- Количество уведомлений в единицу времени
- "Спам" уведомления могут блокироваться
- Тихие уведомления (без звука) могут игнорироваться

### 3. Срок жизни подписки

- Safari может аннулировать подписку, если:
  - Пользователь долго не открывал PWA
  - Приложение было удалено и переустановлено
  - Пользователь очистил данные Safari

### 4. Особенности отображения

- Уведомления всегда показываются в центре уведомлений iOS/macOS
- Иконки могут отображаться по-другому
- Badge (число на иконке) работает иначе

## Проверка поддержки в коде

Наш код автоматически проверяет:

```typescript
// Проверяем, является ли браузер Safari
function isSafari(): boolean {
  const ua = window.navigator.userAgent;
  return /^((?!chrome|android).)*safari/i.test(ua);
}

// Проверяем, установлено ли PWA
function isStandalone(): boolean {
  return (
    window.matchMedia('(display-mode: standalone)').matches ||
    window.navigator.standalone === true
  );
}

// Показываем промпт только если PWA установлено
if (isSafari() && !isStandalone()) {
  // Показываем инструкцию по установке
} else {
  // Показываем промпт для включения уведомлений
}
```

## Решение проблем

### Уведомления не работают в Safari

**Проверьте:**

1. ✅ iOS 16.4+ / macOS Ventura+
2. ✅ PWA установлено (не просто открыто в браузере)
3. ✅ Открыто именно из иконки на домашнем экране
4. ✅ Разрешения даны в Настройках → Уведомления
5. ✅ HTTPS с валидным сертификатом

### "Add to Home Screen" не появляется

**Причины:**
- Некорректный manifest.json
- Отсутствует Service Worker
- Нет HTTPS
- Не хватает обязательных иконок

**Проверьте manifest.json:**
```json
{
  "name": "Looking",
  "short_name": "Looking",
  "display": "standalone",
  "icons": [
    {
      "src": "/icon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    }
  ]
}
```

### Подписка создается, но уведомления не приходят

**Возможные причины:**
1. PWA было закрыто и открыто снова через Safari (не standalone)
2. Пользователь отозвал разрешение в системных настройках
3. Endpoint подписки устарел

**Решение:**
- Переподпишитесь заново
- Проверьте таблицу `push_subscriptions`
- Обновите Service Worker

## Рекомендации для пользователей Safari

1. **Всегда устанавливайте PWA**
   - Добавьте на домашний экран
   - Открывайте ТОЛЬКО из иконки на домашнем экране

2. **Обновите систему**
   - iOS должна быть 16.4 или новее
   - macOS должна быть Ventura или новее

3. **Проверьте разрешения**
   - iOS: Настройки → Уведомления → Looking
   - macOS: Системные настройки → Уведомления → Looking

4. **Очистка данных**
   - Если что-то не работает, удалите PWA
   - Переустановите и дайте разрешения заново
