# Руководство по ленте образов стилистов

## Обзор функционала

Функционал "Лента образов" позволяет стилистам создавать и публиковать свои образы, а пользователям - просматривать, добавлять в избранное и заказывать консультации по понравившимся образам.

## Архитектура решения

### База данных

#### Таблица `stylist_looks`
Хранит информацию об образах:
- `id` - UUID образа
- `stylist_id` - ID стилиста (FK на `stylists.id`)
- `title` - название образа
- `description` - описание образа (опционально)
- `image_url` - URL изображения в Supabase Storage
- `created_at`, `updated_at` - временные метки

#### Таблица `favorite_looks`
Хранит избранные образы пользователей:
- `id` - UUID записи
- `user_id` - ID пользователя (FK на `profiles.id`)
- `look_id` - ID образа (FK на `stylist_looks.id`)
- `created_at` - временная метка
- Уникальный индекс на `(user_id, look_id)`

### Storage

**Bucket**: `looks` (публичный)
- Политики RLS для контроля доступа
- Максимальный размер файла: 5 MB
- Форматы: JPEG, PNG, WebP

## Компоненты

### 1. FeedScreen (`src/screens/FeedScreen.tsx`)

**Главный экран ленты образов**

Функции:
- Отображение всех образов стилистов в виде вертикального списка
- Поддержка pull-to-refresh
- Переход к профилю стилиста
- Кнопка "Заказать образ" - открывает профиль стилиста с модальным окном бронирования
- Добавление/удаление из избранного

### 2. LookCard (`src/components/feed/LookCard.tsx`)

**Карточка образа в ленте**

Содержит:
- Изображение образа (соотношение 3:4)
- Название и описание
- Информацию о стилисте (аватар, имя, ТЦ)
- Кнопку добавления в избранное (сердечко)
- Кнопку "Заказать образ"

### 3. EditStylistProfileScreen (расширенный)

**Управление образами в профиле стилиста**

Новый функционал:
- Просмотр своих образов в виде сетки
- Добавление нового образа (модальное окно)
- Удаление образа
- Загрузка изображения с выбором пропорций 3:4

### 4. lookStore (`src/store/lookStore.ts`)

**Zustand store для управления образами**

Методы:
- `fetchLooks()` - загрузка всех образов для ленты
- `fetchStylistLooks(stylistId)` - загрузка образов конкретного стилиста
- `createLook()` - создание нового образа
- `updateLook()` - обновление образа
- `deleteLook()` - удаление образа
- `fetchFavorites()` - загрузка избранных образов пользователя
- `addToFavorites()` - добавление в избранное
- `removeFromFavorites()` - удаление из избранного
- `isFavorited()` - проверка, добавлен ли образ в избранное

## Пользовательские сценарии

### Для клиентов

#### Просмотр ленты образов
1. Перейти на вкладку **"Лента"**
2. Пролистать образы стилистов
3. Потянуть вниз для обновления (pull-to-refresh)

#### Добавление в избранное
1. Нажать на иконку сердечка на карточке образа
2. Образ добавится в избранное (сердечко станет красным)
3. Повторное нажатие удалит из избранного

#### Заказ консультации по образу
1. Нажать кнопку **"Заказать образ"** на карточке
2. Откроется профиль стилиста
3. Автоматически откроется модальное окно бронирования
4. Выбрать дату, время и ТЦ
5. Оставить комментарий (опционально)
6. Нажать **"Забронировать"**

#### Переход к профилю стилиста
1. Нажать на блок с информацией о стилисте на карточке
2. Откроется детальный профиль стилиста

### Для стилистов

#### Создание образа
1. Перейти на вкладку **"Профиль"**
2. Найти секцию **"Мои образы"**
3. Нажать **"+ Добавить"** (или **"Добавить первый образ"**, если образов еще нет)
4. В модальном окне:
   - Нажать на плейсхолдер и выбрать фото из галереи
   - Ввести название образа (обязательно)
   - Ввести описание (опционально)
   - Нажать **"Добавить"**
5. Образ появится в горизонтальной галерее и в общей ленте

**Преимущества**: Образы управляются прямо из главного экрана профиля, не нужно заходить в редактирование!

#### Удаление образа
1. Открыть вкладку **"Профиль"** → секция **"Мои образы"**
2. Найти нужный образ в горизонтальной галерее
3. Нажать на крестик (✕) на карточке образа
4. Подтвердить удаление

## Технические детали

### Загрузка изображений

```typescript
// Процесс загрузки:
1. Выбор изображения через ImagePicker
2. Сжатие с quality=0.7 и пропорциями 3:4
3. Конвертация в ArrayBuffer
4. Загрузка в Supabase Storage bucket 'looks'
5. Получение публичного URL
6. Сохранение URL в таблицу stylist_looks
```

### Формат названия файлов

```
look-{user_id}-{timestamp}.{ext}
```

Пример: `look-a1b2c3d4-e5f6-7890-abcd-ef1234567890-1699876543210.jpg`

### Запросы к БД

#### Загрузка образов с информацией о стилистах

```typescript
supabase
  .from('stylist_looks')
  .select(`
    id, title, description, image_url, created_at, updated_at,
    stylist_id,
    stylists:stylist_id (
      id, user_id, bio, status, ...,
      profiles:user_id (full_name, avatar_url)
    )
  `)
  .order('created_at', { ascending: false })
```

## RLS Политики

### stylist_looks

- **SELECT**: Все могут просматривать образы (независимо от статуса стилиста)
- **INSERT**: Только стилисты могут создавать свои образы
- **UPDATE**: Только стилисты могут обновлять свои образы
- **DELETE**: Только стилисты могут удалять свои образы

### favorite_looks

- **SELECT**: Пользователи видят только свои избранные
- **INSERT**: Авторизованные пользователи могут добавлять в избранное
- **DELETE**: Пользователи могут удалять из своего избранного

## Troubleshooting

### Образы не отображаются
1. Проверьте настройку bucket `looks` в Storage
2. Проверьте RLS политики для таблиц
3. Убедитесь, что стилисты создали образы

### Ошибка при загрузке изображения
1. Проверьте размер файла (не более 5 MB)
2. Проверьте формат файла (JPEG, PNG, WebP)
3. Проверьте разрешения на доступ к галерее

### Избранное не работает
1. Проверьте авторизацию пользователя
2. Проверьте RLS политики для `favorite_looks`
