# Обзор структуры проекта Looking App

Этот документ описывает структуру проекта и назначение каждой папки.

## Корневая структура

```
looking-app/
├── src/              # Исходный код приложения
├── supabase/         # Конфигурация и функции Supabase
├── scripts/          # Вспомогательные скрипты сборки
├── assets/           # Статические ресурсы (иконки, изображения)
├── public/           # Публичные файлы для веб-версии
├── dist/             # Собранные файлы для production
└── docs/             # Документация проекта
```

## Основные технологии

- **React Native** + **Expo** - кроссплатформенная разработка
- **TypeScript** - типизация
- **Zustand** - управление состоянием
- **React Navigation** - навигация
- **Supabase** - backend и аутентификация
- **React Native Paper** - UI компоненты
