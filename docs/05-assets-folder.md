# Папка assets/ - Статические ресурсы

Исходные изображения и иконки для приложения.

## Структура

```
assets/
├── adaptive-icon.png    # Исходник для Android adaptive icon
├── favicon.png          # Исходник favicon для веб
├── icon.png             # Основная иконка приложения
├── splash-icon.png      # Иконка для splash screen
└── [другие изображения] # Дополнительные ресурсы
```

## Назначение файлов

### icon.png

Основная иконка приложения:
- Используется для iOS и Android
- Должна быть квадратной (1024x1024px рекомендуется)
- Используется как база для генерации всех размеров

### adaptive-icon.png

Исходник для Android adaptive icon:
- Используется для создания адаптивной иконки Android
- Может иметь прозрачные области
- Генерируется в разные размеры автоматически

### favicon.png

Иконка для веб-версии:
- Отображается во вкладке браузера
- Используется для PWA
- Генерируется в разные размеры (16x16, 32x32, 48x48, 192x192, 512x512)

### splash-icon.png

Иконка для splash screen:
- Отображается при загрузке приложения
- Используется на iOS и Android
- Центрируется на экране загрузки

## Генерация иконок

Иконки генерируются автоматически из исходников с помощью скрипта `scripts/generate-icons.js`.

### Процесс генерации

1. Берется исходное изображение из `assets/`
2. Создаются версии разных размеров
3. Сохраняются в нужные папки:
   - `assets/` - для мобильных платформ
   - `public/` - для веб-версии

### Размеры иконок

**iOS:**
- 20x20, 29x29, 40x40, 60x60, 76x76, 83.5x83.5, 1024x1024

**Android:**
- mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi
- Adaptive icon: foreground + background

**Web:**
- 16x16, 32x32, 48x48, 192x192, 512x512
- Apple touch icon: 180x180
- Microsoft tile: 150x150

## Использование в приложении

Иконки настраиваются в `app.json` и `app.config.ts`:

```json
{
  "icon": "./assets/icon.png",
  "splash": {
    "image": "./assets/splash-icon.png"
  }
}
```

## Оптимизация

- Используйте PNG формат для иконок
- Оптимизируйте размер файлов перед добавлением
- Проверяйте качество на разных устройствах
- Используйте прозрачность только где необходимо

## Обновление иконок

1. Замените исходные файлы в `assets/`
2. Запустите `npm run generate-icons`
3. Проверьте результат в `public/` и `assets/`
4. Пересоберите приложение
