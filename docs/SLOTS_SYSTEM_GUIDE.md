# Система слотов бронирования

Руководство по работе системы учета слотов при записи к стилисту.

---

## Обзор

Система слотов обеспечивает:
- ✅ **Предотвращение двойного бронирования** - один стилист не может иметь два активных бронирования на одно время
- ✅ **Учет графика работы** - показываются только слоты в рабочие часы стилиста
- ✅ **Визуализация доступности** - клиент видит свободные и занятые слоты
- ✅ **Real-time валидация** - проверка доступности перед созданием бронирования

---

## Архитектура

### 1. База данных

**Constraint для предотвращения дублирования:**

```sql
ALTER TABLE bookings 
ADD CONSTRAINT unique_stylist_datetime_slot 
UNIQUE (stylist_id, booking_date, booking_time)
WHERE (status IN ('pending', 'confirmed'));
```

**Особенности:**
- Partial unique constraint - применяется только к активным бронированиям
- Отмененные (`rejected`) и завершенные (`completed`) бронирования не блокируют слот
- Защита от race conditions на уровне БД

**Вспомогательные функции:**

1. `get_booked_slots(stylist_id, date)` - получает занятые слоты
2. `is_slot_available(stylist_id, date, time)` - проверяет доступность конкретного слота

---

### 2. Backend (Store)

**Файл:** `src/store/bookingStore.ts`

**Новые функции:**

#### `getBookedSlots(stylistId: string, date: string): Promise<TimeSlot[]>`

Получает список занятых слотов для стилиста на конкретную дату.

**Параметры:**
- `stylistId` - ID стилиста
- `date` - Дата в формате YYYY-MM-DD

**Возвращает:**
```typescript
interface TimeSlot {
  time: string;        // "HH:MM"
  available: boolean;  // всегда false для занятых
  status?: 'pending' | 'confirmed';
}
```

#### `getAvailableSlots(stylistId: string, date: string, workSchedule: WorkSchedule): Promise<TimeSlot[]>`

Генерирует все доступные слоты с учетом графика работы и занятости.

**Логика:**
1. Определяет день недели по дате
2. Получает график работы для этого дня из `workSchedule`
3. Если стилист не работает - возвращает пустой массив
4. Генерирует слоты с интервалом 30 минут от начала до конца рабочего дня
5. Помечает занятые слоты как `available: false`

**Пример:**
```typescript
// Стилист работает с 10:00 до 20:00
// Занято: 14:00 (pending), 16:30 (confirmed)

const slots = await getAvailableSlots(stylistId, '2025-11-07', workSchedule);

// Результат:
[
  { time: "10:00", available: true },
  { time: "10:30", available: true },
  // ...
  { time: "14:00", available: false, status: "pending" },
  // ...
  { time: "16:30", available: false, status: "confirmed" },
  // ...
  { time: "19:30", available: true }
]
```

#### Улучшенная валидация в `createBooking()`

**Двойная защита:**

1. **Проверка перед INSERT:**
   - Получаем актуальный список занятых слотов
   - Проверяем, не занят ли выбранный слот
   - Возвращаем ошибку если занят

2. **Обработка constraint нарушения:**
   - Если два клиента одновременно бронируют один слот
   - PostgreSQL constraint `unique_stylist_datetime_slot` предотвращает дублирование
   - Ловим ошибку `23505` (unique violation)
   - Показываем понятное сообщение пользователю

```typescript
// Код валидации
const bookedSlots = await get().getBookedSlots(
  bookingData.stylist_id, 
  bookingData.booking_date
);

const isSlotTaken = bookedSlots.some(
  slot => slot.time === bookingData.booking_time
);

if (isSlotTaken) {
  set({ 
    error: 'Этот слот уже занят. Пожалуйста, выберите другое время.', 
    loading: false 
  });
  return null;
}
```

### 3. Frontend (UI)

**Файл:** `src/components/booking/BookingModal.tsx`

**Изменения:**

1. **Удален свободный выбор времени через TimePicker**
2. **Добавлена сетка слотов** - визуальное отображение доступных и занятых интервалов

**Новое состояние:**
```typescript
const [selectedTime, setSelectedTime] = useState<string | null>(null); // вместо Date
const [availableSlots, setAvailableSlots] = useState<TimeSlot[]>([]);
const [loadingSlots, setLoadingSlots] = useState(false);
const [workSchedule, setWorkSchedule] = useState<WorkSchedule | null>(null);
```

**Логика загрузки:**

1. При открытии модального окна:
   - Загружаем график работы стилиста
   
2. При изменении даты:
   - Загружаем доступные слоты для новой даты
   - Сбрасываем выбранное время

**UI компоненты:**

```jsx
// Индикатор загрузки
{loadingSlots && (
  <ActivityIndicator size="small" color="#6200ee" />
)}

// Сообщение если нет слотов
{availableSlots.length === 0 && (
  <Text>В этот день стилист не работает или все слоты заняты</Text>
)}

// Сетка слотов
<View style={styles.slotsGrid}>
  {availableSlots.map((slot) => (
    <TouchableOpacity
      key={slot.time}
      disabled={!slot.available}
      onPress={() => setSelectedTime(slot.time)}
    >
      <Text>{slot.time}</Text>
      {!slot.available && (
        <Text>{slot.status === 'confirmed' ? '✓' : '⏱'}</Text>
      )}
    </TouchableOpacity>
  ))}
</View>
```

**Стили слотов:**

- **Доступный слот**: белый фон, фиолетовая рамка
- **Выбранный слот**: фиолетовый фон, белый текст
- **Занятый слот**: серый фон, неактивная кнопка
- **Иконки статуса**: ✓ (подтвержден), ⏱ (ожидание)

## Использование

### Для клиента

1. Открыть модальное окно "Записаться к стилисту"
2. Выбрать дату встречи
3. Дождаться загрузки доступных слотов
4. Выбрать свободный слот (занятые будут неактивны)
5. Указать место встречи и комментарий
6. Нажать "Забронировать"

### Для стилиста

**График работы управляется в профиле стилиста:**

```typescript
work_schedule: {
  monday: { enabled: true, start: "10:00", end: "20:00" },
  tuesday: { enabled: true, start: "10:00", end: "20:00" },
  wednesday: { enabled: true, start: "10:00", end: "20:00" },
  thursday: { enabled: true, start: "10:00", end: "20:00" },
  friday: { enabled: true, start: "10:00", end: "20:00" },
  saturday: { enabled: true, start: "11:00", end: "19:00" },
  sunday: { enabled: false, start: "10:00", end: "20:00" }
}
```

**Параметры:**
- `enabled` - работает ли стилист в этот день
- `start` - время начала работы (HH:MM)
- `end` - время окончания работы (HH:MM)

**Интервал слотов:** 30 минут (фиксированный)

## Обработка ошибок

### Слот уже занят (проактивная проверка)

```
Этот слот уже занят. Пожалуйста, выберите другое время.
```

**Причина:** Слот был занят между загрузкой списка и попыткой бронирования.  
**Действие:** Список слотов автоматически обновляется, выберите другое время.

### Race condition (constraint violation)

```
Этот слот был только что занят другим клиентом. 
Пожалуйста, выберите другое время.
```

**Причина:** Два клиента одновременно забронировали один слот.  
**Защита:** PostgreSQL constraint не позволил создать дубликат.  
**Действие:** Список слотов автоматически обновляется, выберите другое время.

### День недели не рабочий

```
В этот день стилист не работает или все слоты заняты
```

**Причина:** 
- У стилиста `enabled: false` для выбранного дня недели
- ИЛИ все слоты на этот день уже забронированы

**Действие:** Выберите другую дату.

## Технические детали

### Временные зоны

⚠️ **Важно:** Все времена хранятся в формате UTC в базе данных.

- Клиент отправляет: `booking_date: "2025-11-07"`, `booking_time: "14:00"`
- В БД сохраняется: `DATE` и `TIME` в UTC
- При отображении конвертируется в локальную временную зону

### Интервал слотов

Фиксированный интервал: **30 минут**

Для изменения интервала обновите:
1. `bookingStore.ts` → `getAvailableSlots()` → `currentMinute += 30`
2. (Опционально) UI для отображения меньших/больших кнопок

### Производительность

**Оптимизации:**
1. Индексы на `booking_date`, `stylist_id`, `status`
2. Кэширование занятых слотов на клиенте
3. Partial unique constraint (не индексирует rejected/completed)

**Рекомендации:**
- Не запрашивайте слоты для дат в далеком будущем (>3 месяца)
- Используйте paging для списка бронирований стилиста

## Дальнейшие улучшения

### Возможные расширения:

1. **Переменная длительность встречи**
   - Сейчас: все встречи = 30 минут
   - Расширение: выбор длительности (30/60/90 минут)

2. **Блокировка времени стилистом**
   - Стилист может отметить слоты как "занят" без клиента
   - Полезно для перерывов, обеда

3. **Буферное время между встречами**
   - Автоматический интервал между бронированиями
   - Например: 15 минут между встречами

4. **Напоминания**
   - Push-уведомления за N часов до встречи
   - Email/SMS напоминания

5. **Recurring bookings**
   - Регулярные встречи (каждую неделю)

6. **Waitlist**
   - Лист ожидания для занятых слотов
   - Автоматическое уведомление при освобождении
