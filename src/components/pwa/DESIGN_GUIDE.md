# Дизайн-гайд PWA Install Prompt

## Различия между iOS и Android

### 📱 iOS Safari - Нативный стиль Apple

**Особенности дизайна:**

1. **Модальная карточка по центру экрана**
   - Белый фон с закругленными углами (20px)
   - Глубокая тень для объемности
   - Кнопка закрытия (×) в правом верхнем углу

2. **Типографика в стиле iOS**
   - Заголовок: SF Pro Display, 22px, жирный, letter-spacing -0.5
   - Описание: 15px, серый (#666)
   - Текст шагов: 15px, межстрочный интервал 22px

3. **Нумерованные шаги с визуальными индикаторами**
   - Фиолетовые круглые бейджи с номерами
   - Подсветка ключевых слов ("Поделиться", "На экран Домой", "Добавить")
   - Четкая структура 1-2-3

4. **Анимированная подсказка**
   - **Стрелка вниз (↓)** с bounce-анимацией
   - Иконка кнопки Share (□↑) с рамкой
   - Указывает на реальную позицию кнопки "Поделиться" в Safari
   - Анимация: движение вверх-вниз каждые 1.2 сек

5. **Кнопка действия**
   - Фиолетовая (#6200ee)
   - Закругление 12px
   - Текст: "Понятно"

**Цветовая схема:**
- Основной: `#6200ee` (фиолетовый)
- Фон: `#ffffff` (белый)
- Текст: `#000` (черный) и `#666` (серый)
- Overlay: `rgba(0, 0, 0, 0.4)`

---

### 🤖 Android Chrome - Material Design

**Особенности дизайна:**

1. **Bottom Sheet стиль**
   - Появляется снизу экрана
   - Белый фон с закругленными углами (16px)
   - Легкая тень

2. **Простая структура**
   - Заголовок: "Установить приложение"
   - Краткое описание
   - Две кнопки: "Установить" и "Позже"

3. **Кнопки Material Design**
   - Основная кнопка: фиолетовая (#6200ee)
   - Вторичная кнопка: светло-серая (#f0f0f0)
   - Закругление 8px

**Цветовая схема:**
- Основной: `#6200ee` (фиолетовый)
- Фон: `#ffffff` (белый)
- Текст: `#1a1a1a` (темно-серый)
- Вторичный: `#f0f0f0` (светло-серый)

## Анимации

### iOS - Bounce анимация стрелки
```typescript
Animated.loop(
  Animated.sequence([
    // Движение вверх на 10px
    Animated.timing(bounceAnim, {
      toValue: -10,
      duration: 600,
    }),
    // Возврат в исходную позицию
    Animated.timing(bounceAnim, {
      toValue: 0,
      duration: 600,
    }),
  ])
)
```

**Параметры:**
- Амплитуда: 10px
- Длительность цикла: 1.2 сек
- Бесконечный loop

### Android - Fade-in модала
```typescript
animationType="fade"
```

## UX детали

### iOS
✅ **Почему стрелка вниз?**
- Кнопка "Поделиться" в Safari находится **внизу экрана**
- Стрелка физически указывает направление
- Визуально привлекает внимание

✅ **Почему карточка по центру?**
- Не блокирует кнопку Share
- Создает фокус на инструкциях
- Стиль Apple модальных окон

### Android
✅ **Почему Bottom Sheet?**
- Стандарт Material Design
- Не перекрывает контент
- Легко закрывается свайпом вниз

✅ **Почему кнопка "Установить"?**
- Android поддерживает программную установку
- Нативный промпт вызывается по клику

## Адаптивность

### Определение платформы
```typescript
const userAgent = window.navigator.userAgent.toLowerCase();
const isIOSDevice = /iphone|ipad|ipod/.test(userAgent);
```

### Проверка standalone режима
```typescript
const isInStandaloneMode = 
  ('standalone' in window.navigator && window.navigator.standalone) ||
  window.matchMedia('(display-mode: standalone)').matches;
```

## Рекомендации по настройке

### Изменение цветов
Замените `#6200ee` на ваш brand color в следующих местах:
- `iosStepNumber.backgroundColor`
- `shareIconText.color`
- `iosButton.backgroundColor`
- `installButton.backgroundColor`
- `arrowText.color`
- `shareIconBox.borderColor`

### Изменение времени показа
```typescript
setTimeout(() => {
  setShowPrompt(true);
}, 2000); // Измените на нужное значение в мс
```

### Изменение периода повторного показа
```typescript
const dismissalTime = new Date().getTime() + (30 * 24 * 60 * 60 * 1000);
// 30 дней, измените множитель
```
