# PWA Install Prompt

## Описание

Компонент `InstallPrompt` отображает всплывающее уведомление о возможности установки веб-приложения на мобильных устройствах.

## Функциональность

### Android (Chrome, Edge, Samsung Internet)
- Использует нативное событие `beforeinstallprompt`
- Показывает кнопку "Установить" для прямой установки PWA
- Автоматически скрывается после установки

### iOS (Safari)
- Отображает нативно-стилизованный промпт в стиле iOS
- Пошаговые инструкции с визуальными индикаторами
- **Анимированная стрелка**, указывающая на кнопку "Поделиться" внизу экрана
- Визуальная иконка кнопки Share с подсветкой
- Дизайн в стиле Apple с правильными шрифтами и отступами

## Особенности

1. **Автоматическое определение платформы** - распознает iOS и Android
2. **Проверка установленности** - не показывается если PWA уже установлено
3. **Запоминание выбора** - если пользователь закрыл промпт, не показывается 30 дней
4. **Задержка показа** - появляется через 2 секунды после загрузки
5. **Нативный дизайн для iOS** - стилизован под Apple HIG (Human Interface Guidelines)
6. **Анимированные подсказки** - анимация стрелки для привлечения внимания к кнопке Share
7. **Адаптивный UI** - разный интерфейс для iOS и Android

## Использование

Компонент автоматически интегрирован в `App.tsx`:

```typescript
import { InstallPrompt } from './src/components/pwa/install-prompt';

// В рендере
<AlertProvider>
  <AppNavigator />
  <InstallPrompt />
  <StatusBar style="auto" />
</AlertProvider>
```

## Требования

### Service Worker
Для работы PWA требуется зарегистрированный Service Worker (находится в `public/service-worker.js`).

### Manifest
Приложение должно иметь валидный `manifest.json` с:
- `name` и `short_name`
- `icons` (минимум 192x192 и 512x512)
- `start_url`
- `display: "standalone"`

### HTTPS
PWA работает только через HTTPS (или localhost для разработки).

## Хранение данных

Компонент использует `localStorage` для:
- `pwa-install-dismissed` - время когда пользователь закрыл промпт

## Совместимость

- ✅ Android Chrome 76+
- ✅ Android Edge 79+
- ✅ iOS Safari 13+ (с инструкциями)
- ✅ Samsung Internet 11+
- ❌ Desktop браузеры (не показывается на desktop)

## Настройка

Для изменения времени отображения после загрузки, измените timeout в компоненте:

```typescript
setTimeout(() => {
  setShowPrompt(true);
}, 2000); // 2 секунды
```

Для изменения периода скрытия после закрытия:

```typescript
const dismissalTime = new Date().getTime() + (30 * 24 * 60 * 60 * 1000); // 30 дней
```
