## 🛠 Технологический стек (РЕАЛИЗОВАНО)

- ✅ **Frontend**: React Native + Expo (вместо Next.js)
- ✅ **Backend**: Supabase (Auth, PostgreSQL, Real-time)
- ✅ **Карты**: Google Maps через react-native-maps (вместо Яндекс)
- ✅ **State**: Zustand
- ✅ **Навигация**: React Navigation v6
- ✅ **Язык**: TypeScript
- ✅ **Package**: com.looking.app

### Почему Google Maps вместо Яндекс?
- Работает в managed Expo (быстрее MVP)
- Проще интеграция
- Легко мигрировать на Яндекс позже

## 📦 Сборка APK

Приложение **готово к сборке APK** через:

1. **EAS Build** (облачная сборка):
```bash
cd looking-app
eas build --platform android
```

2. **Локальная сборка**:
```bash
cd looking-app
npx expo prebuild
cd android && ./gradlew assembleRelease
```

## 🚀 Как запустить (БЫСТРЫЙ СТАРТ)

### Шаг 1: Перейти в проект
```bash
cd looking-app
```

### Шаг 2: Настроить Supabase (5 мин)
1. Создать проект на supabase.com
2. Выполнить SQL из `supabase-migration.sql`
3. Создать файл `.env`:
```env
EXPO_PUBLIC_SUPABASE_URL=https://ваш-проект.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=ваш-ключ
```

### Шаг 3: Настроить Google Maps (3 мин)
1. Получить API ключ: console.cloud.google.com
2. Добавить в `app.json` → `android.config.googleMaps.apiKey`

### Шаг 4: Запустить
```bash
npx expo start
```

Сканировать QR код в Expo Go!
