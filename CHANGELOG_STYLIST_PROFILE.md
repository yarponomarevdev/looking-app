## 🎯 Новые возможности профиля

### 1. Фамилия Имя Отчество ✅
- Хранится в таблице `profiles` как `full_name`
- Указывается при регистрации
- Отображается везде: на карте, в списке, в профиле

### 2. Фото профиля ✅
- Поле `avatar_url` в таблице `profiles`
- Отображается в карточках и детальном профиле
- Загрузка фото запланирована на будущее

### 3. Установка статуса ✅
- **3 статуса:** Available (Свободен), Busy (Занят), Offline (Офлайн)
- **Быстрое переключение** в профиле через кнопки
- **Фильтрация:** стилисты с offline не показываются
- **Real-time обновление** на карте и в списке

### 4. Социальные сети ✅
- **4 платформы:** Instagram, VK, Telegram, WhatsApp
- **Формат:** JSON объект `social_links` (JSONB)
- **Отображение:** в детальном профиле с иконками
- **Редактирование:** отдельные поля для каждой сети

### 5. Информация о себе ✅
- Поле `bio` для описания опыта и специализации
- Многострочное текстовое поле в редакторе
- Отображается в детальном профиле и кратко в Bottom Sheet

### 6. График работы ✅
- **Структура:** JSON объект с 7 днями недели
- **Параметры:** enabled (вкл/выкл), start (начало), end (конец)
- **По умолчанию:** Пн-Пт 10:00-20:00, Сб 11:00-19:00, Вс выходной
- **Редактирование:** переключатели + поля времени
- **Отображение:** только рабочие дни в детальном профиле

### 7. Торговые центры (множественный выбор) ✅
- **Изменено:** `current_mall` (строка) → `malls` (массив)
- **27 ТЦ** на выбор из списка
- **Обязательно:** минимум 1 ТЦ
- **Отображение:**
  - На карте: первый ТЦ + "и еще N"
  - В списке: первый ТЦ + "и еще N"
  - В профиле: полный список
- **Редактирование:** тэги с множественным выбором

### 8. Бренды одежды (тэги) ✅
- **45+ популярных брендов** в списке
- **Категории:** масс-маркет, средний сегмент, премиум, люкс, спорт, российские
- **Кастомные бренды:** можно добавлять свои вручную
- **Отображение:**
  - В профиле: все тэги компактно
  - На карте/списке: первые 3 + "..."
- **Редактирование:** выбор из списка + добавление своих

## 📊 Структура новой схемы БД

### Таблица `stylists`

```sql
CREATE TABLE stylists (
  id UUID PRIMARY KEY,
  user_id UUID UNIQUE,                           -- Ссылка на profiles
  bio TEXT,                                      -- О себе
  status TEXT DEFAULT 'available',              -- Статус (available/busy/offline)
  latitude DOUBLE PRECISION,                     -- Широта
  longitude DOUBLE PRECISION,                    -- Долгота
  malls TEXT[],                                  -- 🆕 Массив ТЦ
  brands TEXT[],                                 -- 🆕 Массив брендов
  social_links JSONB,                            -- 🆕 Социальные сети
  work_schedule JSONB,                           -- 🆕 График работы
  portfolio_images TEXT[],
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);
```

### Примеры данных

**social_links:**
```json
{
  "instagram": "stylist_name",
  "vk": "https://vk.com/stylist_name",
  "telegram": "@stylist_name",
  "whatsapp": "+79991234567"
}
```

**work_schedule:**


1. **Войдите в приложение**
2. **Перейдите в "Профиль"**
3. **Нажмите "✏️ Редактировать профиль"**
4. **Заполните все секции:**
   - Установите статус (Свободен)
   - Напишите о себе
   - Укажите социальные сети
   - Выберите ТЦ (минимум 1)
   - Выберите бренды
   - Настройте график работы
5. **Нажмите "Сохранить изменения"**

## 🔄 Миграция существующих данных

Если у вас уже есть стилисты в БД, выполните:

```sql
-- Добавить новые колонки (если миграция уже выполнялась)
ALTER TABLE stylists 
  ADD COLUMN IF NOT EXISTS malls TEXT[] DEFAULT ARRAY[]::TEXT[],
  ADD COLUMN IF NOT EXISTS brands TEXT[] DEFAULT ARRAY[]::TEXT[],
  ADD COLUMN IF NOT EXISTS social_links JSONB DEFAULT '{}'::JSONB,
  ADD COLUMN IF NOT EXISTS work_schedule JSONB DEFAULT jsonb_build_object(
    'monday', jsonb_build_object('enabled', true, 'start', '10:00', 'end', '20:00'),
    'tuesday', jsonb_build_object('enabled', true, 'start', '10:00', 'end', '20:00'),
    'wednesday', jsonb_build_object('enabled', true, 'start', '10:00', 'end', '20:00'),
    'thursday', jsonb_build_object('enabled', true, 'start', '10:00', 'end', '20:00'),
    'friday', jsonb_build_object('enabled', true, 'start', '10:00', 'end', '20:00'),
    'saturday', jsonb_build_object('enabled', true, 'start', '11:00', 'end', '19:00'),
    'sunday', jsonb_build_object('enabled', false, 'start', '10:00', 'end', '20:00')
  );

-- Мигрировать current_mall в malls (если было поле current_mall)
UPDATE stylists 
SET malls = ARRAY[current_mall]::TEXT[] 
WHERE current_mall IS NOT NULL AND malls = ARRAY[]::TEXT[];

-- Удалить старую колонку (опционально)
ALTER TABLE stylists DROP COLUMN IF EXISTS current_mall;
```
